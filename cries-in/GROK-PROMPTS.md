Commons file names below are REFERENCE only, so Richey/Grok can match the real sound. Do not ship Commons wavs into the house; licenses are not automatically house-ok. Grok video remains the ship path.

If Wikipedia describes a vocalization, the prompt uses that. If Wikipedia is silent — plants, fungi, microbes, most fish, mouthless moths — the prompt stays honest quiet (water, rustle, rasp, bubble). Far-den aliens and grid dragons have no species article; those ticks stay invented and marked house, not Wikipedia.
